# Quiz System

A full-stack web-based Quiz System designed for conducting online quizzes, managing questions, evaluating student responses, and displaying quiz results.

The system provides separate functionality for **Administrators** and **Students**, with server-side validation for quiz submissions and time restrictions.

---

## Features

### Admin

- Create and manage quizzes
- Add and manage quiz questions
- Set quiz difficulty
- Configure quiz duration
- Schedule quizzes with start and end time
- Manage quiz status
- Track number of submissions
- View student responses
- Validate submitted answers
- Calculate student marks
- View quiz statistics
- Manage active and scheduled quizzes

### Student

- Enter student profile details
- Start available quizzes
- View questions dynamically
- Select and update answers
- Real-time quiz timer
- Automatic answer validation
- Submit quiz
- View quiz result
- Prevent duplicate submissions
- Prevent submission after quiz closure
- Track remaining quiz time

---

## Quiz Timing

The system supports two types of quiz timing:

### Duration Based

A quiz can be configured with a fixed duration such as:

- 15 minutes
- 30 minutes
- 45 minutes
- 60 minutes
- Custom duration

### Scheduled

A quiz can also be scheduled using:

- Start time
- End time
